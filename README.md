**OpenLIT is the open-source agent harness engineering platform: trace, evaluate, guard, and improve everything around the model in your AI agents, on OpenTelemetry.**

This repository is the source for [openlit.io](https://openlit.io), the marketing site for OpenLIT. The product itself lives in [openlit/openlit](https://github.com/openlit/openlit).

OpenLIT gives teams OpenTelemetry-native agent observability, evaluations, guardrails, prompt management, and cost and GPU monitoring for AI agents and coding agents. It is free to self-host under Apache 2.0.

## What does "LIT" mean in OpenLIT?

**OpenLIT** is the product name for this open-source agent harness engineering platform. It is **not** Google's Learning Interpretability Tool (LIT). If you are looking for Google's model-interpretability UI, see the [Learning Interpretability Tool glossary entry](https://developers.google.com/machine-learning/glossary#learning-interpretability-tool-lit).
